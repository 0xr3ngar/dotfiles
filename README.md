# dotfiles

Low-effort personal configs. macOS (yabai / Ember) and Arch (niri / God-King).

Each OS folder mirrors your home (`arch/.config/…`, `arch/.zshrc`, etc.). `common/` is shared.

## Arch

```bash
git clone https://github.com/0xr3ngar/dotfiles.git ~/dotfiles
bash ~/dotfiles/arch/setup.sh
```

Fresh machine via archinstall: [`arch/archinstall/README.md`](arch/archinstall/README.md)

```bash
bash ~/dotfiles/arch/test-in-docker.sh   # smoke-test the installer
```

## macOS

```bash
git clone https://github.com/0xr3ngar/dotfiles.git ~/dotfiles
bash ~/dotfiles/macos/setup.sh
```
